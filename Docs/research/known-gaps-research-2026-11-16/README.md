documented known gaps could be closed, run against YouKnow 1.4.9 at commit
`6b92c51`. `youknow-known-gaps-2026-11-16-combined.md` is the combined,
sourced report; the per-researcher reports, the brief (`-prompt.md`) and the
source register (`-sources.md`, `-sources.json`) are beside it.

the repository from a local snapshot, and the snapshot's local path in the
brief and in the Codex report's local sources S1–S8 is replaced by the same
files at `6b92c51` on GitHub; and the researchers' model identifiers are
reduced to Claude, Codex and Gemini.

What was done with the findings: the analysis of the captures already in hand
is [`../existing-capture-analysis-2026-11-16.md`](../existing-capture-analysis-2026-11-16.md),
